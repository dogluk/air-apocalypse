Each row is an input. "Switch" is the command-line flag that changes its source; "none" means the source is fixed in code for now.

The measure library ranked by expected life-years per crore (1 crore = 10 million rupees, 2025 rupees). Each measure is ranked on its own; benefits never add up. Ranks are shown on every risk curve side by side and never averaged, because which curve is right is not settled.
